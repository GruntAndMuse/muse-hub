# First-Actions Checklist: "You Just Woke Up Here"

Do these three, in order. Fifteen minutes, then you're working — not before.

## Action 1 — Orient (who / whom / what)
- [ ] Read the injected standing files (SOUL, IDENTITY, USER, MEMORY, AGENTS, HEARTBEAT, TOOLS). Know who you are, who you're helping, and how this shop works.
- [ ] Read today's daily log (`~/memory/YYYY-MM-DD.md`). If thin, read yesterday's.
- [ ] You can now answer: *who is the user, what's active today, and what happened most recently?* If you can't, keep reading — don't proceed to action.

## Action 2 — Survey live state (what's real right now)
- [ ] List goals: what's active, what's closed.
- [ ] List scheduled jobs: what ran recently, what's due next, anything failing.
- [ ] List tracked items: commitments with real-world outcomes pending.
- [ ] Note the single most time-sensitive thing (a flight, a deadline, a failing job). Everything else waits behind it.

## Action 3 — Ground the task (verify before touching)
- [ ] Read the project's `goals/<slug>/GOAL.md`.
- [ ] Read the **tail** of its active working files (`hidden_files/` — logs, specs, run state).
- [ ] For any "next step" the files name: verify it against a live source (today's log, current goal/job status, the file's own tail). Stale next-steps are the norm, not the exception.
- [ ] Check the research cache / relevant registries before re-deriving any technical fact.
- [ ] Only now: begin the actual task.

## The workspace map (this shop's layout)
- `~/workspace/goals/<slug>/` — one dir per goal: `GOAL.md` (notes), `files/` (user-facing deliverables), `hidden_files/` (working state: logs, specs, watermarks)
- `~/workspace/your_files/` — files meant for the user to see/download
- `~/workspace/skills/` — installed skills (one dir each, `SKILL.md` inside)
- `~/workspace/muse-hub/` — shared registries, NOW/NEXT boards, research
- `~/workspace/research-cache/` — verified technical findings (check before researching)
- `~/workspace/browser/` — browser tooling, block registry, API test clients
- `~/memory/` — daily logs (`YYYY-MM-DD.md`), curated `MEMORY.md`, people/groups indexes
- `~/AGENTS.md`, `~/HEARTBEAT.md`, `~/TOOLS.md`, `~/USER.md`, `~/SOUL.md` — standing files (injected every session)

## Done criteria
You can state, with sources: who the user is, what's active, what the task's true current state is, and what you deliberately skipped. "I verified X against <source>" beats "the summary said X" every time.
