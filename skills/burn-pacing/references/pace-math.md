# Pace Math — Worked Example

Dennis's setup, kept as the worked example. The discipline is the skill;
these numbers are his. Measure your own before trusting a rate.

## Observed rates (free weekly allowance era, % of weekly limit)

- Sustained reading/writing/analysis labor: **~1 pt per 45–90 min.** Planning rate: **1.25 h/pt.**
- Mixed interactive work (downloads, lookups, light reasoning): ~1 pt per 3h elapsed — far cheaper than sustained labor.
- Natural background pace (no dedicated burn): ~4 pts/day.
- Best multi-day sustained: 12–16 pts/day. Single-day ceiling observed: 28.6 pts/day (never repeated).

## The formula

```
hours_before_reset = (target_pct − current_pct) × 1.25 + 1–2h buffer
```

Start the burn when the formula says to — not the night before reset.

## The Friday burn-math run (2026-10-09, real)

- 11% used, reset in 106.75h wall-clock. Paper target 99%.
- (99 − 11) × 1.25 = 110h sustained labor + buffer vs 106.75h available → short by ~4–5h before the buffer.
- Away-mode natural pace ≈ 3–4 pts/day would land ~25–29% untouched; needs ~19.8 pts/day for 99%.
- Verdict: BEHIND. Direct warning sent with the numbers. Target lowered to 50%: (50−11)×1.25 = 48.75h + 2h buffer ≈ 50.75h vs 106.75h wall — fits with ~56h slack, no rushing.
- Dennis accepted the lowered target the same morning ("no nead to rush").

## Guardrails

- 5% emergency reserve — the burn never touches it.
- If pace projects over 95% before reset, drop the lowest-value recurring work first (his: the daily hunt searches), keeping the untouchable tranche and assigned burn intact.
- If the start-time math already passed, the target is lowered — never the pace compressed.

- Effect: scarcity math is dead. The lowered-target rule relaxes — but the weekly cycle still resets, so the weekly burn still runs (use-it-or-lose-it). The war chest funds the big builds; the weekly funds the rhythm.
