# goals

## Summary
Guidance for creating and working with user goals (the Goals tab).

## When to use / vs alternatives
Read before creating a goal when no creation contract is in context, and when
helping with an existing goal. On a Goals-tab creation turn the contract is
injected — do NOT re-read the files then.

## Quality notes
SKILL.md read in full (56 lines). The key insight is the context routing:
injected contract vs read-it-yourself, and never re-running creation
choreography on an existing goal ("running that choreography again restarts
intake on a goal the user is already working on"). Subtle and correct.

## Gotchas
- Confirm the goal's category with `user_goal.get` before reading a scaffold.
