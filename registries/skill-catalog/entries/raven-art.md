# raven-art

## Summary
Workflow for generating GruntAndMuse raven (Muninn) illustrations that are
anatomically and technically correct: reference images, explicit anatomy
specs, composite-first for exact designs, red-pen before showing Dennis.

## When to use / vs alternatives
Any Muninn/raven illustration work (site art, show assets, thumbnails).
For non-raven image generation, use the media tools directly without this
workflow.

## Quality notes
SKILL.md is a living document — lessons appended first-hand from the
2026-10-10 site art session (13 generations). Covers: tool anatomy specs
that work, why the generator can't reproduce exact designs, the
composite-first workflow (PIL perspective warp + visual grounding), chat
attachment caching, and deploy batching discipline. The composite approach
 beat 4 failed AI attempts at drawing the K2 riser.

## Gotchas
- Image budget ~16 generations/day — the workflow exists to stop burning it.
- "Using the tool" must be named explicitly or the raven poses beside it.
- Never show Dennis a version worse than the previous one; change approach.
