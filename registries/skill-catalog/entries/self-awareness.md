# self-awareness

## Summary
Ground self-referential answers ("what can you do?", "what do you remember?")
in the actual filesystem, not guesses.

## When to use / vs alternatives
Any "who are you / what can you do / what do you know" question. The rule is
re-read the files every time — never answer from cached assumptions.
